# ねこパズル：アプリ設計書

## 1. 概要

お祭り会場のiPadで遊ぶ、子供向けのねこ写真ジグソーパズルWebアプリ。

子供が写真を選び、分割されたピースをドラッグして正しい場所に置き、元の写真を完成させる。未就学児から小学生までが短時間で遊べるものにする。

## 2. 目的と方針

- 猫を題材に、楽しく遊べる体験を提供する
- Webアプリが「画像・デザイン・プログラム」で作られることを展示で伝える
- 最初の版は短期間で安定して作れることを優先する
- アカウント、個人情報、サーバーへの保存は扱わない
- iPad Safariでの横向き表示を主な利用環境とする

## 3. 利用の流れ

```text
スタート画面
  ↓
写真を選ぶ
  ↓
むずかしさを選ぶ
  ↓
パズル画面（選択した難易度の分割数）
  ├─ ピースをドラッグして正しい場所へ置く
  ├─ 完成していなければ続ける
  └─ 完成したら完成画面へ
                    ↓
             もう一度あそぶ
                    ↓
              スタート画面
```

## 4. 画面設計

iPad横向きでは、ブラウザのツールバー表示時の高さ（`100svh`）を基準に、選択・パズル・完成の各画面をページスクロールなしで表示する。猫写真は4列で並べ、盤面と完成写真は高さに合わせて縮小する。ピース置き場は難易度に応じて4・6・8列にし、48枚もすべて画面内に表示する。縦向き・狭い画面では従来の縦スクロール表示を使用する。

### 4.1 スタート画面

表示するもの：

- タイトル「ねこパズル」
- 遊び方の短い説明
- 選択できる猫写真の一覧
- 難易度の選択肢（かんたん・ふつう・むずかしい）
- 「この写真であそぶ」ボタン

写真カードと難易度をタップすると選択状態になり、選んだ内容でゲームを開始する。初期状態では「かんたん」を選択する。

### 4.2 パズル画面

表示するもの：

- 選択した写真のタイトル
- 選択した難易度に応じたパズル盤面
- 下部のピース置き場
- 「ピースをドラッグして、おなじばしょにおこう」という案内
- 「はじめから」ボタン

操作：

1. ピース置き場から1枚のピースを指で押さえる
2. 盤面の正しい場所まで動かす
3. 指を離す
4. 正しい場所ならピースが枠に収まり、違う場所ならピース置き場に戻る
5. すべてのピースが正しい場所に収まったら完成とする

ピース置き場ではピースの順番をランダムにするが、盤面上の写真をシャッフルしない。盤面には完成写真を薄く表示して、ピースを置く場所の目印にする。

### 4.3 完成画面

表示するもの：

- 「かんせい！」などのお祝いメッセージ
- 完成した猫写真
- 「もう一度あそぶ」ボタン
- 「ちがう写真をえらぶ」ボタン

## 5. パズルの仕様

### 初期版

| 項目 | 内容 |
| --- | --- |
| 難易度 | かんたん・ふつう・むずかしい（初期値はかんたん） |
| マス数・ピース数 | かんたん：4×3・12枚、ふつう：6×4・24枚、むずかしい：8×6・48枚 |
| ピースの並び | ピース置き場でランダムに並べる。盤面の写真はシャッフルしない |
| 操作 | ピースを指でドラッグし、盤面の正しい枠で離す |
| 誤った場所に置いた時 | ピース置き場に戻す |
| 完成判定 | 選択した難易度のすべてのピースが対応する枠に置かれた時 |
| タイマー・得点 | 初期版ではなし |

### 写真の表示方法

1枚の写真を選択した難易度の数だけ分割して見せる。各ピースには同じ写真を背景として使用し、CSSの背景位置をずらして対応する部分だけを表示する。盤面には同じ写真を薄く表示し、正しい位置を分かりやすくする。むずかしいでは、横向きは48枚を一度に表示し、縦向き・狭い画面では縦スクロールできる置き場に表示する。

この方式では、画像をあらかじめ9ファイルに分割する必要がない。

## 7. 猫写真データの管理

### 7.1 写真ファイルの配置場所

猫写真は次のフォルダに置く。

```text
public/images/cat-images/
```

写真は横向きで、4:3の構図を推奨する。写真の中央付近に猫の顔や特徴があると、パズルにしたときに分かりやすい。アプリ内の盤面とピースは4:3に固定して表示する。4:3素材は比率を変えずに表示され、異なる比率の素材は4:3に合わせて表示される。

推奨形式：JPEG または WebP

### 7.2 写真一覧JSON

アプリが選択肢として表示する写真は、次のJSONで定義する。

```text
public/data/cat-images.json
```

JSON配列の各要素が1枚の写真を表す。`isEnabled` が `true` の写真だけを選択画面に表示する。

| 列名 | 必須 | 内容 | 例 |
| --- | --- | --- | --- |
| `id` | 必須 | 写真を識別する重複しないID | `cat-01` |
| `fileName` | 必須 | `public/images/cat-images/` 内のファイル名 | `cat-01.jpg` |
| `title` | 必須 | 画面に表示する名前 | `しろねこ` |
| `altText` | 必須 | 写真を説明する文 | `窓辺に座る白い猫` |
| `isEnabled` | 必須 | 選択画面に表示するか | `true` |
| `sortOrder` | 必須 | 表示順。小さい数から先に表示 | `1` |

各項目はJSONの形式に従って記述する。文字列は二重引用符で囲み、項目の間にはカンマを付ける。ただし、配列の最後の要素の末尾にカンマは付けない。

### 7.3 写真を追加する手順

1. 利用許諾を確認した写真を `public/images/cat-images/` に配置する
2. ファイル名を半角英数字とハイフンで付ける（例：`cat-03.jpg`）
3. `public/data/cat-images.json` に写真の情報を1つ追加する
4. ブラウザで開き、選択画面・パズル画面の両方で正しく表示されることを確認する

## 8. 実装方針

HTML、CSS、JavaScriptのみを使用し、外部ライブラリやデータベースは初期版では使用しない。

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の土台を置く |
| `src/style.css` | iPadで見やすく、タップしやすい見た目を作る |
| `src/app.js` | JSONの読み込み、画面切替、ピース置き場のシャッフル、ドラッグ操作、完成判定を行う |
| `public/data/cat-images.json` | 選択可能な写真の情報を持つ |

### 動作させる方法

JSONはJavaScriptで読み込むため、アプリは `file://` ではなく、HTTPで配信するWebサーバー経由で開く。お祭り当日は、会場内のノートPCなどで簡易Webサーバーを動かし、iPadのSafariから同じWi-Fi内のURLを開く方式を想定する。

サーバーはアプリのデータを保存したりインターネットに接続したりするものではなく、HTML・CSS・JavaScript・画像・JSONをiPadに渡すためだけに使用する。
