# おまつり ねこジグソーパズル：制作記録

このファイルは、アプリをどう考え、どう作ったかを残すための記録です。展示では、子供にも読みやすい言葉に要約して使えます。

## 0. はじめに：作るものを決める

### 目的

お祭りに来た子供がiPadで楽しく遊びながら、「Webアプリは人が考えて作っている」ことを知る。

### 選んだ出し物

ねこ写真を使ったジグソーパズル。

### この案を選んだ理由

- 説明を読まなくても、触ってすぐに遊び始められる
- 年齢に合わせてピース数を変えられる
- 猫という会社らしい題材を使える
- 最初の版はサーバーやログインが不要で、短期間で作れる

## 1. 最初の仕様（作る前の設計）

### 遊び方

1. 猫の写真と難易度を選ぶ
2. バラバラになったピースをタップして入れ替える
3. 写真が完成したら、お祝いの画面を表示する
4. 「もう一度あそぶ」で最初に戻る

### 最初の版に入れるもの

- 1枚の猫写真
- 3×3（9ピース）のパズル
- タップによるピース交換
- 完成の判定
- リスタートボタン

### 最初の版では入れないもの

- アカウント作成・得点保存
- 写真のアップロード
- 外部サービスとの連携
- 複雑なドラッグ操作

これらを後回しにすると、個人情報を扱わず、iPadで安定して遊べる最小版を早く完成させられる。

## 2. 技術の選び方

HTML、CSS、JavaScriptだけで作る。

- **HTML**：画面にボタンやパズルを並べる
- **CSS**：かわいく、大きく、押しやすい見た目にする
- **JavaScript**：ピースを混ぜる・入れ替える・完成を判定する

特別なソフトを使わず、Safariで開けるWebページにする。iPadにアプリをインストールしなくても使えるのが利点。
